# CyberHive

**Bee Safe, Bee Secure**

CyberHive is a marketing website for a SaaS product that helps small companies and startups run penetration testing and vulnerability scanning on their websites — without the enterprise price tag or the enterprise wait time.

## About the project

Most professional security testing is priced and scoped for companies that already have security teams and six-figure budgets. CyberHive exists to close that gap: fixed-fee, fast-turnaround pentesting and vulnerability scanning built specifically for lean teams.

This repo contains the front-end site: a single-page layout covering the product pitch, the team, and a contact form for inbound leads.

## Pages / sections

- **Home** — hero, mission statement, services (manual pentesting, automated scanning, plain-language reports, retesting), and a step-by-step breakdown of how an engagement runs.
- **About Us** — team profiles.
- **Contact Us** — a lead-gen form (name, email, company, website, message) that emails submissions automatically.

## Tech stack

- HTML5
- CSS3 (custom properties, no framework)
- Vanilla JavaScript (no build step, no dependencies)

## Project structure

```
cyberhive/
├── index.html      # all page markup and content
├── styles.css       # design tokens, layout, components
└── script.js        # nav behavior, scroll animations, terminal animation, form submission
```
